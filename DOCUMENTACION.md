# GymFit Manager
## Parte 3 · Mini test con usuarios

### 1. Objetivo de la prueba

El objetivo de esta prueba es comprobar la facilidad de uso de GymFit Manager mediante la realización de una tarea de alta de un nuevo socio.

### 2. Tarea propuesta

Los usuarios deben realizar la siguiente tarea:

«Da de alta a Laura Gómez Ruiz, nacida el 14/05/2003, de Sevilla, con cuota Joven y la clase de Spinning».

### 3. Resultados del mini test

Se realizaron dos pruebas con compañeros o familiares utilizando el prototipo de GymFit Manager.

| Medición | Resultado |
|---|---|
| Usuarios participantes | 2 |
| Tarea completada | Sí |
| Tiempo empleado | Sin medición registrada |
| Errores o dudas | Validación del IBAN |
| Satisfacción | Sin valoración registrada |

### 4. Errores encontrados

Durante la realización de la tarea, el único error encontrado estuvo relacionado con el IBAN.

La aplicación indicaba que el IBAN debía comenzar por ES y tener 24 caracteres. Fue necesario introducir un IBAN que cumpliera esas condiciones para poder continuar con el alta.

### 5. Conclusión

La prueba ha permitido comprobar que GymFit Manager permite realizar el alta de un nuevo socio. El único problema encontrado fue la validación del IBAN, que exige que empiece por ES y tenga 24 caracteres. He aprendido que los mensajes de validación deben ser claros y ayudar al usuario a corregir los errores. Como mejora, facilitaría la introducción y validación del IBAN para evitar dudas durante el registro.
